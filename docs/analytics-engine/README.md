# Ready Set STEM Analytics Platform

## Purpose

The Analytics Platform provides permission-scoped operational and financial reporting for leadership and staff. It consists of:

1. **Analytics Experience** — pages, filters, executive summaries, drill-through, search, PDF, and Excel.
2. **Analytics Engine** — canonical filters, periods, metrics, rankings, financial calculations, and deterministic decision rules.
3. **Analytics Governance** — definitions, lineage, permissions, validation, operations, and controlled change.

This directory documents the engine as implemented on July 23, 2026. Documentation does not grant permission to change formulas through the UI.

## Current architecture

```text
React analytics pages
        |
```

## Current delivery model

- Analytics are calculated on demand from the operational database.
- There is no analytics warehouse, scheduled refresh, materialized view, calculation cache, or stored analytics snapshot.
- The main analytics endpoint currently computes a broad payload used by multiple pages; focused engine modules provide its calculations.
- Costs & Margin uses the same endpoint with completed-month and explicit comparison filters.
- Executive summaries are generated by deterministic, documented rules.
- Core formulas are controlled in reviewed code.

## Governing principles

1. The backend is the authoritative source for metrics and permissions.
2. Identical filters must reconcile across headline values, charts, drill-through, and exports.
3. Core formulas are changed through code review, tests, documentation, and deployment.
4. UI-editable configuration is limited to approved operational settings and thresholds.
5. Historical operational and financial facts are preserved by default.
6. Every result must be explainable by source population, date basis, formula, filters, and version.
